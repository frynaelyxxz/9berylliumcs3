# ILA 3-1: Applying the Four Pillars of OOP

## Sari-Sari Store Inventory System

### 1. Encapsulation
I'm going to use encapsulation to bundle all the variables a product needs into one neat package.

### 2. Abstraction
Product labels will use a minimalist design to eliminate user distraction.

### 3. Inheritance
To avoid the repetetiveness of creating many functions for products that have similar variables

### 4. Polymorphism
To track the quantity of the inventory because you can use the same function for multiple purposes because polymorphism is very flexible


## Reflection
Inheritance is the most useful tool for a sari-sari store system. All items in your shop share the same basic details: name, price, and stock quantity. Instead of writing new code for canned goods, chips, and sodas, you can crate one main product blueprint. This saves you from rewriting the same code over and over again for every item u sell.
